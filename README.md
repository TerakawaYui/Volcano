# Volcano V5

天文 FITS 第一帧中的环／弧结构检索。统一流程，不使用GT、历史目标位置或人工白名单。

## 运行

已配置本机Python环境时：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "E:\VSCodeFile\DiffDonuts\Volcano_v5\run.ps1" -FitsPath "G:\FitsArchive\G_Mosaic\G002.5+0.0IFx_Mosaic.fits" -Workers 3
```

脚本自动建立新的输出目录。中断后用相同参数加 `-OutputDir "原输出目录"` 续跑。
源码、配置或输入变化时必须换新目录，不能混用旧缓存。

其它机器可用Python建立 `.venv`，然后安装 `requirements.txt`。直接Python入口：

```text
python main.py INPUT.fits --output OUTPUT --workers 3
```

读取目录会逐文件检测。`run.ps1`对目录输入默认加载`settings/archive_beams.json`；
补充表按`G:\FitsArchive`根目录的相对路径组织。缺波束的单文件须显式传入
`-BeamArcsec`，例如GLOSTAR用已有资料和紧致源估计支持的18角秒近似。
补充表不修改原FITS头；VE产品处理含义及亮度单位仍未确认。

## 算法

1. 读取第一张二维天球图，保留原像素、缺测值及WCS；不平均不同物理轴。
2. 多阈值亮包络扫描；重叠窗口提出环状滤波和亮区域候选。
3. 对原像素联合拟合背景、非负点源和卷积后的椭圆高斯环。完整环、单弧及双弧共享几何参数。
4. 完整环与最佳弧分别验证。原图具有足够近完整环壁和中心凹陷时，再拟合带两个角向亮度参数的完整环；该拟合不减点源，并与相同角向自由度的实心盘作四折空间块留出比较。
5. 所有模型使用同一套环壁、连续弧长、背景显著性和竞争模型条件分级。减点源前也必须有环壁支持，不能只依靠减中心源后的暗孔。
6. 按等级及证据选择候选，跨窗口去重，输出两级目录。

径向轮廓为`exp[-(rho-r)^2/(2w^2)]`，`w`是卷积前标准差。
V4没有`r/w >= 2/3`分级门槛，也没有厚环特例接受分支。`r/w`仅报告为描述量。
宽度仍参与模板、优化范围、横向采样和背景区域选择，因此V5并非对厚度完全不敏感。
原有候选半径2.7–32像素、拟合半径参数上限34像素，及宽度边界仍保留；尚未保证全尺度完备。
新增完整环拟合每窗口最多两次，严重断裂目标仍依赖弧模型。

## 输出与图

- `result/`：高等级候选。
- `unconfirmed_result/`：需要人工复核的候选。
- `catalog.csv`：去重后的候选及银河坐标。
- `measurements.csv`：全部测量与排除原因。
- `firstcheck/`、SQLite、配置与进度记录：断点续跑所需数据。

图像面板均以原FITS WCS显示**绝对银河经度l、纬度b**；赤道WCS会转换为银河坐标覆盖层，
不是把像素轴改名。每个目标另附固定8扇区和角度—半径图。
径向图用角秒，角度—半径图是模型诊断而非天空位置图，故不用l/b替换其物理量。
亮度显示范围自适应，显示调整不影响算法输入或分级。

条件SNR与分级均不是已校准概率。空间块相邻像素仍相关；留出比较不是独立天区验证。
CGPS波束采用图中心的圆形等效近似，尚未建模椭圆PSF及空间变化。
所有巡天的整图准确率／召回率尚待独立验证，保留两级结果供复核。

开发脚本、GT、历史结果、测试与验收图均放在项目外，V5不附带这些开发资料。

## V5 与 V4 的确切差异

V4 已取消 r/w 分级门槛；V5 沿用，不把此事算作新改动。宽度仍影响模板、采样和优化边界。
V5 保留候选扫描、尺度范围、拟合方式、点源处理和去重规则；不使用目标白名单。
显示仍用自适应上下限和银河 WCS，显示变换不进入拟合，不用截断或 asinh 图像替代观测。

设 L0 为无环基线残差平方和，Lr 为环模型残差平方和，Ld 为实心盘模型残差平方和。
这些损失在相同有效像素、相同噪声单位下计算；竞争模型分别重新拟合允许的参数。

- `flat_advantage_legacy=(Lr-Ld)/max(L0-Lr,1)`：保留 V4 定义。
- `flat_advantage=(Lr-Ld)/max(Ld,1)`：V5 相对残差比较。负数表示环优于实心盘。
- 待复核底线仍要求 legacy <= 0.15；不会单凭新分母把旧实心盘检验不合格者放进候选集。
- 高等级要求新 flat <= -0.02，即环的剩余平方误差比实心盘至少低 2%（Ld>=1 时）。
  这改变了阈值的含义，并非同样严格的等价改写。它不是概率或统计显著性。

`background_center_shift` 保留外侧噪声单位下的原值；
`background_context_shift=background_center_shift/max(1,wall_context_scatter)`，
后者绝对值需 <= 2.5 才能进入 result。context_scatter 来自既有外侧上下文起伏估计，
不是背景均值的标准误差。上下文显著性原有条件仍然适用，防止只靠背景尺度增大而晋级。

V5 比相对评分试验更保守：进入 result 时，扣点源前的原图也必须满足
已有高等级环壁覆盖率、内侧落差和外侧落差条件，分别为 0.65、1、1.5。
原图证据不够高等级但满足弱条件时，只保留在 unconfirmed_result；
原有原图伪环否决仍可直接排除。原图高等级证据缺失时不能晋级。
`original_high_wall_pass` 在目录中说明这一检查是否通过。

完整环的四折空间块留出比较、致密源团竞争、环壁连续性与曲率检查均保留。
全部高等级条件必须同时满足，评分函数不修改输入测量。
分母改变和背景标准化都可能使部分旧弱候选晋级；原图条件也可能使旧强候选降级，
因此不能承诺保持旧目录逐对象不变。需要用全图结果评估精度，局部正例测试不足以保证。

V5 使用独立缓存签名，不能在 V4 输出目录续跑。请使用新输出目录。
